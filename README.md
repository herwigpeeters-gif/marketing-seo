# Marketing SEO & Executive Education Dashboards

A centralized repository containing SEO analytics, keyword strategy dashboards, content cluster mappings, and competitor benchmarking reports for Executive Education programs (Executive MBA and Digital Transformation & Leadership - DTSL) at Antwerp Management School (AMS) vs. competitors (e.g., Vlerick Business School).

---

## 🚀 Repository Structure

| File | Description |
| --- | --- |
| `index.html` | The primary hub / landing page providing centralized access to all dashboards and resources. |
| `Executive-MBA-SEO-Strategy-Dashboard.html` | Interactive dashboard for Executive MBA SEO performance, keyword tracking, content clusters, gap analysis, and AI content roadmap. |
| `Executive-DTSL-SEO-Strategy-Dashboard.html` | Interactive dashboard for Digital Transformation & Leadership (DTSL) keyword rankings, content cluster maps, and growth actions. |
| `mba-seo-audit.html` | Competitor benchmarking dashboard comparing AMS vs. Vlerick Business School SEO performance and strategic keyword opportunities. |

---

## 🛠 Tech Stack

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **Chart.js** (via CDN for dynamic analytics visualization)
- **Vanilla JavaScript** (embedded data models and interactive UI controls)

---

## 💻 Local Development & Usage

No build tools or backend server required. You can serve the static files locally using any lightweight HTTP server or open directly in a web browser.

### Option 1: Python HTTP Server

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your web browser.

### Option 2: Direct File Access

Open `index.html` directly in any standard browser (Chrome, Safari, Firefox, Edge).

## 📊 Key Dashboards & Features

1. **Executive MBA Strategy Dashboard**
   - Track gaining vs. at-risk keywords
   - Analyze competitor keyword gaps (Vlerick vs. AMS)
   - Explore strategic content clusters (Career Advancement, Flexible Formats, Global Exposure, ROI)
   - AI-driven prompt ideas for content generation

2. **DTSL Strategy Dashboard**
   - High-impact search intent analysis for digital leadership & transformation
   - Keyword position distribution and movement tracking

3. **SEO Competitor Audit**
   - Head-to-head traffic and positioning analysis for AMS vs. Vlerick
   - Target persona pain points and keyword alignment
